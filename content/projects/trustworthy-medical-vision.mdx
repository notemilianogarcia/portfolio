# Trustworthy Medical Vision

Rigorous ML pipeline for binary chest X-ray classification emphasizing model calibration, uncertainty quantification, and trustworthy decision-making. The system evaluates **when classifier outputs should be trusted**, **when predictions warrant caution**, and **when decisions should be deferred**.

## TL;DR

- **Production baseline**: DenseNet-121 achieving **0.9576 AUROC**, **0.8990 accuracy**, **0.9240 F1** on 624 test cases
- **Comparator model**: ResNet-50 with **0.9713 AUROC**, **0.8798 accuracy** for complementary evaluation
- **Calibration pipeline**: Adaptive temperature scaling and reliability diagram analysis (ECE, Brier scores)
- **Uncertainty quantification**: MC Dropout inference with selective prediction and abstention policies
- **Explainability validation**: Grad-CAM generation with untrained model sanity checks and stability metrics (Spearman correlation, spatial robustness)
- **Failure audit**: 4-mode taxonomy across 63 analyzed error cases; ensemble + deferral reduces estimated cost by 36.63%
- **Interactive demo**: https://trustworthy-medical-vision.vercel.app/ showcasing per-case analysis and system-level metrics

## What I Built

This is not a competition for raw accuracy. It is a **trustworthiness study** showing that reliability signals—calibration, uncertainty, explanation consistency, and failure semantics—matter more than confidence alone.

**Dataset & Benchmarking**

Binary pneumonia classification on the **Kaggle Chest X-Ray Images dataset** with patient-level deterministic train/validation/test splits to prevent leakage. Data pipeline includes class balance analysis, augmentation strategies, and split reproducibility via seeding.

**Baseline Training**

Trained DenseNet-121 and ResNet-50 as primary and comparator models using transfer learning from ImageNet-pretrained weights. Weighted BCE loss addresses class imbalance. Checkpoints selected on validation AUROC with early stopping. Both models achieved AUROC > 0.95, forming a strong foundation for downstream analysis.

**Calibration Analysis**

Temperature scaling improved miscalibration; ECE analysis showed that deterministic confidence alone is insufficient. Implemented adaptive binned calibration with configurable bin edges (default: `[0.0, 0.6, 0.8, 1.0]`). Reliability diagrams visualize alignment between predicted confidence and empirical accuracy. Brier scores and calibration metrics are archived per run.

**Uncertainty Quantification**

MC Dropout implemented with strategic placement—classifier head and late feature blocks—yielding nuanced uncertainty signals. MC inference with T passes (default 20) produces uncertainty estimates (predictive entropy, mutual information). Compared against deterministic confidence baselines. Selective prediction curves show accuracy-retention trade-offs when abstaining on high-uncertainty cases.

**Explainability Infrastructure**

Grad-CAM visual explanations generated for all test cases, curated by prediction state (correct/incorrect, high/low confidence). Sanity checks validate against untrained model baseline to detect explanation artifacts. Explanations stored with metadata linking to predictions and confidence scores.

**Explanation Stability**

Tested explanation robustness under mild perturbations (brightness/contrast adjustments, ±5° rotations). Computed Spearman rank correlation (ranking consistency), spatial overlap (IoU top-k regions), and center-of-mass drift. Stability metrics enable detection of brittle explanations despite stable predictions.

**Failure-Case Audit & Trust Synthesis**

Systematic audit of all 63 misclassifications across DenseNet and ResNet, categorized into 4 modes (clinical ambiguity, annotation noise, model blindness, spurious features). Curated case studies with markdown documentation. Trust quadrants synthesized prediction correctness, confidence, and explanation stability into actionable trust states.

**Cross-Model & Ensemble Analysis**

DenseNet and ResNet made 32 disagreements across 624 test cases. Deep dive analysis revealed complementary strengths: ResNet better for ranking (AUROC), DenseNet better for calibration. Trained 3-model ensemble (DenseNet121, ResNet50, EfficientNet-B0) with deferral policies. Ensemble + deferral achieved **36.63% estimated cost reduction** in failure scenarios.

**Interactive Web Demo**

Next.js application with dual browsing modes: representative cases and difficult/stress-test cases. Per-case panels show prediction, confidence, uncertainty, Grad-CAM, and sanity checks. System-level insights include calibration curves, selective prediction, stability distributions, cross-model diagnostics, ensemble performance, and OOD robustness analysis.

## Why It Matters

**ML/Research Discipline**

This project demonstrates disciplined evaluation in a high-stakes domain. It prioritizes reproducibility (deterministic splits, artifact versioning), multi-dimensional assessment (accuracy + calibration + uncertainty + explanation + failure taxonomy), and responsible AI framing (explicit limitations, disclaimer). The stack shows how ML reliability is built methodically, not assumed.

**ML Engineering**

Production ML systems must operate safely under uncertainty. This project shows how to quantify uncertainty, detect miscalibration, and design deferral policies. Temperature scaling, MC Dropout placement, and selective prediction are practical reliability mechanisms. Failure audits convert error patterns into actionable insights. The system trades raw accuracy for trustworthiness—acknowledging when predictions are ambiguous or risky.

**Software Engineering & Deployment**

The codebase is modular, reproducible, and maintainable. 8-stage pipeline with clear responsibility boundaries. Config-driven workflows (configs/default.yaml). All artifacts (checkpoints, metrics, explanations, case studies) are versioned and archived. CI/CD pipeline with pytest for validation. Web demo turns raw outputs into interactive insights, enabling stakeholders to explore results without technical setup.

## Key Results

**Model Performance**

| Metric | DenseNet-121 | ResNet-50 |
|--------|--------------|-------------|
| AUROC | 0.9576 | 0.9713 |
| Accuracy | 0.8990 | 0.8798 |
| F1 | 0.9240 | 0.9117 |

**Reliability Signals**

- Temperature scaling improved calibration; MC Dropout sensitivity to model uncertainty varied by architecture
- Selective prediction showed 2-3% accuracy gains when abstaining on top 10% uncertainty cases
- Explanation stability (Spearman > 0.85) correlated with correct predictions; unstable explanations often preceded errors

**Failure Analysis**

- Cross-model disagreement: 32 of 624 cases (5.1%)
- Oracle ensemble accuracy: 0.9151 (removing all disagreements)
- Deferral policy reduced estimated failure cost by 36.63%
- Failure modes: clinical ambiguity (40%), annotation errors (25%), model blindness (20%), spurious features (15%)

**System-Level Insights**

The project demonstrates that asking **when the model should be trusted** yields more value than asking **how accurate is the model**. Calibration adjustments improve reliability signals without changing raw accuracy. Uncertainty and explanation stability distinguish cases where high confidence is justified from cases where it masks fragility. Ensemble disagreement reveals complementary model strengths. Deferral policies quantify the cost-benefit of abstention.

## Responsible AI & Safety

### Important Disclaimers
- **Research/educational project for methodological validation only**
- **Not a medical diagnostic tool or approved for clinical use**
- Requires medical professional review before any healthcare application

### Ethical Considerations
- Dataset reflects demographic patterns in training data; external validation on diverse populations required
- Explanations are model-derived signals, not ground truth
- Calibration and stability metrics are dataset-dependent and may not generalize

### Limitations
- Single-source dataset; external validation on independent cohorts needed before clinical claims
- Failure due to dataset bias, labeling noise, or domain shift cannot be fully ruled out
- Model decisions should never override radiologist judgment

## Project Overview

This project builds a medical image classification system that treats **confidence** and **explanations** as first-class outputs alongside predictions. The technical contribution is not "beating SOTA," but demonstrating **responsible ML research** and **production-minded ML engineering** by analyzing when the model should be trusted and when it should not.

**Core idea:** In healthcare-relevant ML, a model's accuracy can look strong while its **confidence is miscalibrated** and its **explanations are unstable**. This project treats explanations as **objects of measurement**, not just visuals.
